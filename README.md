# 日経平均 終値予想ノート

日経平均の終値を予想する催しのために、予想と結果を記録して検証するスマホ向けのアプリです。寝る前にスマホ片手で、1分以内に入力を終えられるように作りました。補正の根拠は「何円の補正を、どの数字を理由に行ったか」の形で必ず残ります。

ブラウザだけで動き、ホーム画面に追加するとアプリと同じように起動できます。記録の保存先は端末の中です。一度開いた後は、通信がなくても入力と閲覧ができます。

## 予想値の決め方

予想値は手で入力しません。先物の値を出発点にして、根拠のある補正だけを足し引きします。

```
予想値 ＝ 先物（投票時） ＋ 補正① ＋ 補正②の合計
```

補正①は先物と日経平均の値の差です。補正②は自分の判断による補正で、何件でも登録できます。1件ごとに理由の種類、金額、根拠にした数字やメモを持ちます。金額が0以外で根拠が空のときは保存できません。

補正①の初期値には、前回の記録の「終値 − 終値が出た頃の先物」を整数に丸めて使います。この値が入っていなければ、前回の補正①をそのまま引き継ぎます。

## 自動で計算する項目

計算は画面と切り離し、`src/calc/calc.ts`にまとめました。もとになる値が未入力の項目は、0ではなく空欄になります。

| 項目 | 計算 |
| --- | --- |
| 予想誤差 | 終値 − 予想値 |
| 先物のみの誤差 | 終値 − 先物（投票時） |
| 補正の効果 | \|先物のみの誤差\| − \|予想誤差\| |
| 夜間の動き | 先物（翌朝） − 先物（投票時） |
| 寄り付きの差 | 始値 − 先物（翌朝） |
| 日中の動き | 終値 − 始値 |
| 補正②の1件ごとの効果 | \|その補正だけを外した場合の誤差\| − \|予想誤差\| |

補正の効果がプラスなら、補正したことで終値に近づいています。マイナスなら補正しないほうが近い値でした。

朝に修正した日は、修正時の先物で予想値を計算し直します。夜の予想値も消さずに残します。この日の計算の基準は次のとおりです。

- 予想値、予想誤差、先物のみの誤差、補正の効果は、朝の先物と朝の補正で計算します。
- 夜間の動きは、夜に投票したときの先物で計算します。
- 夜の予想値とその誤差も別に計算し、検証タブでは朝の修正で誤差が何円縮まったかの平均を出します。

検証タブでは件数が20件未満の集計に「件数が少ないため参考値」と表示します。

## 開発

Node.js 22で動作を確かめています。

```sh
npm install
npm run dev    # 手元で起動する
npm test       # 計算の自動テストを流す
npm run build  # 公開用のファイルを dist/ に作る
```

使っているのはReact、TypeScript、Viteです。端末内の保存にはIndexedDB、通信なしで動かす仕組みとホーム画面への追加にはvite-plugin-pwaを使っています。

自動テストは`test/`にあります。確かめる数字は、依頼時に示された10/05の記録の予想値70100、予想誤差583.98、先物のみの誤差633.98、補正の効果50です。書き出したJSONを読み込むと同じ状態に戻ることもテストしています。

## GitHub Pagesで公開する

1. GitHubで`nikkei-yosou`という名前のリポジトリを作ります。
2. このフォルダの中身を`main`ブランチにpushします。
3. リポジトリのSettings → Pagesを開き、Sourceを「GitHub Actions」にします。
4. `.github/workflows/deploy.yml`が動き、テスト、ビルド、公開の順に進みます。進み具合はActionsタブで見られます。
5. 終わると`https://<ユーザー名>.github.io/nikkei-yosou/`で開けます。

以後は`main`にpushするたびに自動で公開し直します。

リポジトリ名を`nikkei-yosou`以外にしたときは、`vite.config.ts`の`base`を`/<リポジトリ名>/`に変えてください。環境変数`BASE_PATH`で渡すこともできます。

アプリを更新したときは、スマホでアプリを一度開いてから閉じ、もう一度開くと新しい版に切り替わります。

## スマホのホーム画面に追加する

公開したURLをスマホで一度開いてから、次の手順で追加してください。

- iPhoneはSafariで開き、共有ボタンから「ホーム画面に追加」を選びます。
- AndroidはChromeで開き、右上のメニューから「ホーム画面に追加」または「アプリをインストール」を選びます。

一度通信がある状態で開けば、その後は機内モードでも入力、保存、履歴の閲覧ができます。

## 最初のデータを読み込む

10/02と10/05の記録は、公開するコードには入れていません。`seed/initial-data.json`に分けてあり、このフォルダは`.gitignore`でリポジトリの対象から外しています。

1. `seed/initial-data.json`をスマホに移します。AirDrop、iCloud Drive、自分宛てのメールなど、どの方法でもかまいません。
2. ホーム画面に追加したアプリを開き、検証タブの下にある「設定とデータ」から「JSON を読み込む」を押します。
3. ファイルを選び、「置き換えて読み込む」を押します。

読み込むと、今の記録はすべてファイルの中身に置き換わります。

## データの保存と書き出し

記録はその端末のブラウザの中（IndexedDB）にだけ保存し、サーバーには送りません。次のような場合に記録が消えたり見えなくなったりします。

- iPhoneのSafariは、しばらく開いていないサイトのデータを消すことがあります。ホーム画面に追加して使うと消えにくくなります。
- ホーム画面に追加したアプリとSafariで開いたページは、保存場所が別です。片方で入れた記録は、もう片方からは見えません。
- ブラウザの履歴やサイトデータを消すと、記録も消えます。

そのため、検証タブの「設定とデータ」から、ときどきJSONを書き出して保存してください。画面には最後に書き出した日時を出しています。書き出したJSONを読み込めば、別の端末でも同じ状態に戻せます。

スプレッドシート用には、タブ区切りでの書き出しを用意しました。「コピーする」を押してから、スプレッドシートの左上のセルに貼り付けてください。列の並びは、依頼時に指定された23列のあとに「投票区分」と「夜の予想値」を足した25列です。朝に修正した日は、先物（投票時）、補正①、補正②、投票時刻の列に朝の値を出します。

複数の端末で同じデータを使う仕組みは作っていません。後から足すときは、保存の処理をまとめた`src/storage/index.ts`の中身を差し替えます。

## 普段使うサイトを開くボタン

先物、ダウ、ナスダック、ドル円の欄の横と、結果の入力の順位の欄の横に「開く」ボタンがあります。予想を保存した直後の画面にも「予想値をコピー」と「投票サイトを開く」を並べました。ボタンを押すと別のタブでサイトが開きます。

アプリはリンクを開くだけで、サイトのページを読み取ることも、投票サイトへ自動でログインすることもしません。入力中の内容は端末に一時保存しているので、サイトを見て戻っても消えません。保存ボタンを押すと一時保存は消えます。

リンク先は、検証タブの下にある「設定とデータ」で変えられます。投票サイトのアドレスは初期値を空にしてあるので、最初に設定で登録してください。登録するまでは、ボタンの代わりに登録の案内が出ます。

## マイナスの入力

iPhoneの数字キーボードにはマイナスの記号がありません。そこで、マイナスになりうる欄（補正、ダウ、ナスダック、ドル円）には「＋/−」のボタンを置き、押すと符号が切り替わるようにしました。

## 先物や終値を自動で取得できるか

今回は自動取得を作らず、無料で使える取得元があるかどうかだけを調べました（2026年10月時点）。

| 取得元 | 取れるもの | 調べた結果 |
| --- | --- | --- |
| 日経平均プロフィル（日経の公式サイト） | 日経平均の日々の終値 | ダウンロードセンターから、直近3年分の日次データを無料でダウンロードできる。手で落とすための仕組みで、API はない。利用規約が自動取得を認めているかは確かめられなかった。 |
| JPX の J-Quants API | 先物の四本値（日中・夜間別） | 先物の四本値は月額16,500円の Premium プランでしか取れない。無料プランは12週間遅れのデータで、先物は対象外。 |
| JPX のデータ配信サービス | 先物の四本値 | 有料。無料で夜間取引の終値を落とせる公式の場所は見つからなかった。 |
| FRED（米セントルイス連銀）の NIKKEI225 | 日経平均の日々の終値 | 無料で、API キーを取れば機械的に取得できる。再配布には日経の許可が要る。何日遅れで更新されるか、ブラウザから直接呼べるか（CORS）は確かめられなかった。先物はない。 |
| stooq | 日経平均の日々の終値 | 2026年3月ごろから CSV の取得に API キーが要るようになり、1日の取得回数にも上限がある。利用規約上の扱いとブラウザから直接呼べるかは確かめられなかった。 |
| Alpha Vantage | 主に米国株 | 無料枠は1日25回まで。日経平均や日経225先物に対応しているかは確かめられなかった。 |
| Yahoo!ファイナンス | 株価全般 | 公式のAPIがなく、ページから抜き出す方法になる。データ自体が他社からの提供で、機械的な取得には向かない。 |

この結果から、次の二つの理由で今回は自動取得を作りませんでした。

一つ目は、このアプリで一番欲しい「日経225先物の夜間取引の終値」と「終値が出た頃の先物」を、無料で規約上も問題なく取れる取得元が見つからなかったことです。二つ目に、このアプリはサーバーを持たずスマホのブラウザだけで動きます。そのため、ブラウザから直接呼べない取得元は、中継のサーバーを別に用意しないと使えません。

もし作るなら、現実的なのは日経平均の終値だけをFREDのAPIから取る方法です。ただしFREDのAPIキーをアプリに埋め込むことになり、ブラウザから直接呼べない場合は中継の仕組みも要ります。毎日1回、自分の手で終値を打つ手間と比べると、今のところ見合わないと判断しました。

調べたときに見たページは次のとおりです。

- [日経平均プロフィル ヒストリカルデータ](https://indexes.nikkei.co.jp/nkave/archives/data?list=all)
- [J-Quants API](https://jpx-jquants.com/ja)、[先物四本値の仕様](https://jpx-jquants.com/spec/drv-bars-daily-fut)
- [JPX 有料のデリバティブ情報](https://www.jpx.co.jp/markets/paid-info-derivatives/index.html)
- [FRED NIKKEI225](https://fred.stlouisfed.org/series/NIKKEI225)
- [pandas-datareader の stooq に関する issue](https://github.com/pydata/pandas-datareader/issues/1012)
